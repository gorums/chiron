# Monthly Marketing Report — One Page

**Use with:** M13 (analytics) and M15 (budget and incrementality)
**Time to fill:** 60 minutes, once you have done it twice
**Audience:** a founder, a manager, or a client who is not a marketer

The reader has ten minutes and a business to run. They need to know one thing: is this working, and what should they do. Everything on this page serves that.

**Hard rules:**

- One page. If it does not fit, cut the charts, not the thinking.
- No metric appears without a comparison — to target, to last month, or to last year.
- Never present a number you cannot explain the cause of.
- Bad news goes at the top, not in an appendix.

## 1. Headline result vs. target

Three lines. This is the only part some readers will finish, so it must stand alone.

```
Result:
Target:
Verdict: on track / behind / ahead / too early to say
```

Then one sentence explaining it in plain language, with the cause, not the number restated.

```

```

**Filled example:**

```
Result:  31 new customers, blended CAC 288 EUR
Target:  28 new customers, CAC under 340 EUR
Verdict: Ahead on volume and cost.

We beat the target because the catch-up offer converted at nearly twice the
rate of the old demo offer, not because we spent more or because traffic grew.
Traffic was actually down 6%.
```

That last clause is what makes the report useful. It tells the reader which lever to pull next.

**If you are behind, write it exactly as plainly:**

```
Result:  19 new customers, blended CAC 465 EUR
Target:  28 new customers, CAC under 340 EUR
Verdict: Behind on both.

Paid search volume fell 22% after a competitor entered the auction and pushed
CPCs from 1.10 to 1.55 EUR. We held spend flat rather than bidding up, which
was the right call on the numbers but leaves a gap we have no second channel
to fill yet.
```

## 2. The metric tree

Show how the headline number is built. This is what lets a non-marketer see where the change actually happened rather than taking your word for it.

| Level | Metric | This month | Last month | Change | Target |
|-------|--------|------------|------------|--------|--------|
| Outcome | New customers | | | | |
| Outcome | Revenue from new customers | | | | |
| Outcome | Blended CAC | | | | |
| Driver | Sessions | | | | |
| Driver | Conversion rate to lead | | | | |
| Driver | Leads | | | | |
| Driver | Lead to customer rate | | | | |
| Driver | Average deal / order value | | | | |
| Health | Churn / retention | | | | |
| Health | Branded search volume | | | | |

**Filled example:**

| Level | Metric | This month | Last month | Change | Target |
|-------|--------|------------|------------|--------|--------|
| Outcome | New customers | 31 | 24 | +29% | 28 |
| Outcome | Blended CAC | 288 EUR | 372 EUR | -23% | <340 |
| Driver | Sessions | 5,410 | 5,760 | -6% | — |
| Driver | Lead CVR | 5.2% | 3.4% | +53% | 4.0% |
| Driver | Leads | 281 | 196 | +43% | 230 |
| Driver | Lead to customer | 11.0% | 12.2% | -10% | 12% |
| Health | Monthly churn | 2.3% | 2.5% | -0.2pp | <2.5% |
| Health | Branded search | 640 | 590 | +8% | — |

Read the tree aloud: sessions fell, lead conversion rose sharply, lead quality dipped slightly, net result strongly positive. The story is visible without any commentary, which is the test of a good tree.

**One rule:** the drivers must multiply out to the outcome. If they do not, you have chosen decorative metrics rather than a tree.

## 3. What changed and why

Three to five bullets. Each one names a cause, not a coincidence, and states the confidence level honestly.

| What moved | Direction | Why we think so | Confidence |
|------------|-----------|-----------------|------------|
| | | | High / Medium / Low |
| | | | |
| | | | |

**Filled example:**

| What moved | Direction | Why | Confidence |
|------------|-----------|-----|------------|
| Lead conversion rate 3.4% → 5.2% | Up | New catch-up offer launched 4 Oct; the rate stepped on that exact date and holds across both traffic sources | High |
| Sessions -6% | Down | We cut the display line and let paid search run flat while CPCs rose | High |
| Lead-to-customer 12.2% → 11.0% | Down | A free assessment attracts more people who are just curious; this is the expected trade and we still net more customers | Medium |
| Branded search +8% | Up | Possibly the LinkedIn posts; possibly seasonal (October is a filing month). Cannot separate the two yet. | Low |

**The "Low" row is the most professionally credible line in the report.** Naming what you cannot yet attribute is what separates a marketer from a person presenting a dashboard. Do not delete it to look more certain.

## 4. What we learned

Two or three things, stated as transferable knowledge rather than as events.

```
1.
2.
3.
```

**Filled example:**

```
1. The offer was the constraint, not the traffic. We spent four months
   optimising ads against a demo request nobody wanted. Changing what we asked
   for beat every bid and creative change we made all year.
2. Free assessments convert to paid at 21% — high enough to fund giving them
   away, but each one costs 40 minutes of delivery time, so this scales to
   about 45/month before it needs a process change.
3. Our tracking was double-counting form submissions from returning visitors.
   September's numbers were roughly 8% overstated. Fixed on 12 Oct; the tree
   above uses corrected figures for both months.
```

Item 3 is the kind of thing people hide. Put it in. Reporting your own measurement errors is how a client comes to trust the numbers you do report.

## 5. What we are doing next month

Three to five actions. Each with an owner, a date, and the expected effect. Nothing vague.

| # | Action | Why (which finding it follows from) | Owner | By | Expected effect |
|---|--------|-------------------------------------|-------|-----|-----------------|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |

**Filled example:**

| # | Action | Why | Owner | By | Expected effect |
|---|--------|-----|-------|-----|-----------------|
| 1 | Roll the catch-up offer into paid social and the email list | It is the only proven lever we have | A. | 8 Nov | +8-12 customers/mo |
| 2 | Add a 3-question qualifier before the assessment booking | Recover the lead-to-customer dip without losing volume | A. | 12 Nov | Lead-to-customer back to ~12% |
| 3 | Build the assessment delivery template | We hit the 45/month ceiling in December otherwise | A. + delivery | 20 Nov | Halves delivery time per assessment |
| 4 | Hold a 15% geographic holdout on LinkedIn for 8 weeks | We cannot currently tell if brand activity is doing anything | A. | Starts 1 Nov | An honest read by January |

Every action traces back to a numbered finding above. If an action does not trace to a finding, ask why it is on the list.

## 6. What we need from you

The section most reports omit and every reader wants. Be specific about what is blocked and what it costs to stay blocked.

| # | What we need | From whom | By when | What happens if we don't get it |
|---|--------------|-----------|---------|----------------------------------|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

**Filled example:**

| # | Need | From | By | If not |
|---|------|------|-----|--------|
| 1 | Decision on publishing prices on the site | Founder | 8 Nov | The pricing page test is blocked; it is currently our highest-expected-value test |
| 2 | 45 minutes with two recent customers for video testimonials | Delivery lead | 20 Nov | Paid social creative stays at four angles; we are seeing fatigue at ~8 days |
| 3 | Agreement to hold the LinkedIn holdout for the full 8 weeks even if it looks quiet | Founder | Before 1 Nov | We will never know whether the brand spend is incremental, and we will keep arguing about it |

Number 3 pre-commits the reader to a decision while they are calm, which is the point of writing it down in a report rather than raising it during a bad week.

## What good looks like

A non-marketer can read it in ten minutes and correctly answer three questions: is this working, why, and what do I need to decide. The metric tree multiplies out. At least one item admits low confidence or an error. Every next-month action traces to a finding, and every "need from you" states the cost of inaction. Written the same way in a bad month as in a good one.

## Common failure

The dashboard dump: twenty charts, no argument, and the reader left to decide for themselves what it means. Its close cousin is the good-news filter, where a bad month is reported through whichever metric happened to rise — impressions, reach, engagement rate. Both destroy trust, but slowly enough that you do not notice until the budget conversation. Lead with the number that matters, even when it is the wrong direction, and you will be believed the month you have something good to report.
